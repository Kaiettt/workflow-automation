# 4.4 task — Version list / detail + Run UI

Source: `4.4-execution-run-ui.md`. Depends on 4.1 (`POST /api/executions`). GET versions live in the designer module (`findByWorkflowId` / `findById` already exist).

## Do — backend

1. `GET /api/workflows/:id/versions` — versions the caller owns, newest `version_number` first. DTO: `id`, `versionNumber`, `publishedAt` (no full definition).
2. `GET /api/workflows/:id/versions/:versionId` — same metadata plus `definition`. 404 if id mismatch or not owned.
3. `{ success, data }` envelope. JWT guard.

## Do — frontend (`frontend/src/features/workflow`)

1. Add `@tanstack/react-query` as a **direct** dependency. Wrap the app with `QueryClientProvider` (devtools already present).
2. Wire `react-router-dom`. Routes:
   - `/workflows/:workflowId` — keep designer reachable
   - `/workflows/:workflowId/versions` — list
   - `/workflows/:workflowId/versions/:versionId` — detail + Run
3. List page: React Query → list endpoint; each row links to detail (`versionNumber`, `publishedAt`).
4. Detail page: show version number, published time, node names / `data.key` from `definition.nodes`. **Run** mutation → `POST /api/executions` with that version id. Disable while pending. After success show execution `status` and per-node log status (error message if failed).
5. Components do not call axios. Use `workflow.api.ts` / `workflow.service.ts` (or an `execution` service) + React Query hooks.
6. Tailwind + existing shadcn `Button`. Read-only node summary; no new canvas.
7. From the designer, add a control to open the versions list for the current `workflowId` after publish.

## Tests

- Backend integration: list/detail 200 for owner; 404 for unknown version; definition on detail matches the published snapshot.
- Frontend: hook/service or component tests with mocked API — list renders versions; Run posts the detail page’s version id.

## Do not

Edit a published version. Execution history index (latest Run response on detail is enough). Fixing OAuth `credential_id` placeholder in the designer.
