## Problem Statement

To complete the MVP workflow (Manual -> Google Sheet -> Filter -> Gmail), the execution engine needs to securely access user credentials and interact with third-party APIs (Google Sheets and Gmail).

## Solution

Implement integration node handlers for `integration.google_sheet.readRows` and `integration.gmail.send`. These handlers must fetch the encrypted credential from the database, decrypt it in memory, and use it to perform the API requests.

## User Stories

1. As a user, I want the Google Sheet node to connect to my spreadsheet and read the rows, so that data can be processed in my workflow.
2. As a user, I want the Gmail node to send emails on my behalf using my connected account, so that I can automate customer outreach.

## Implementation Decisions

- **Credential Resolution**: 
  - Update the Execution Engine to resolve `credential_id` from the node's config.
  - **Note**: Both Google Sheets and Gmail nodes will reference the *same* Google OAuth credential (since we use a unified Google connector with both scopes).
  - Fetch the `connector_credentials` record, decrypt the `encrypted_secret` (AES-256-GCM), and provide it to the handler.
  - Ensure the plaintext secret is *never* logged to `execution_node_logs`.
- **Google Sheet Handler**: 
  - Implement logic using the Google APIs client to read rows from the specified `spreadsheet_id` and `sheet_name`.
  - Format the output as an array of JSON objects.
- **Gmail Handler**:
  - Implement logic to take an array of items (from the Filter node) and loop over them.
  - For each item, interpolate the `{{variables}}` in the `to`, `subject`, and `body` fields.
  - Send the email via the Gmail API.
- **Error Handling**: Catch API errors (e.g., invalid token, rate limits) and map them to a `FAILED` status in `execution_node_logs`.

## Testing Decisions

- **Unit Tests**: Mock the Google API clients to test the handler logic without making real network calls. Verify that variables are correctly interpolated in the Gmail handler.
- **Security Check**: Ensure that tests verify the `encrypted_secret` is not leaked into the return payload or logs.

## Out of Scope

- Implementing the OAuth flow for users to connect their accounts (we rely on the MVP seed script for credential data).
