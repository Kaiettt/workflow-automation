## Testing Decisions

- Backend integration: list/detail 200 for owner; 404 for unknown version; definition on detail matches the published snapshot.
- Frontend: hook/service tests or component tests with mocked API — list renders versions; Run posts the detail page’s version id.

## Out of Scope

- Editing a published version (immutable).
- Execution history index (detail may show only the latest Run response).
- Fixing OAuth `credential_id` placeholder in the designer (still required for a live Google run).
