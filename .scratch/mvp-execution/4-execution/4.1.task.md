Source: `4.1-execution-engine-foundation.md`. Contract: `contracts.md`. Fixture: `definition.json`.

## Do

1. Add Nest lib `monolith-backend/libs/execution` (Clean Architecture + CQRS). Register it in `AppModule`. kebab-case files.
2. Domain: `INodeExecutor` as in `contracts.md`. Registry map `key → INodeExecutor`. Never `switch` on `data.key`.
3. Register four stub executors (mock I/O, log `SUCCESS`):
   - `ManualTriggerExecutor` (`trigger.manual`)
   - `GoogleSheetReadRowsExecutor` (`integration.google_sheet.readRows`)
   - `FilterExecutor` (`logic.filter`)
   - `GmailSendExecutor` (`integration.gmail.send`)
4. Walk `definition.edges` in array order: first `edges[0].source`, then each `target`; require `edges[i].source === edges[i - 1].target`. Do not start from `trigger.manual`. Do not invert edges.
5. `POST /api/executions` body `{ "workflow_version_id": string }`. JWT. Synchronous: return after traversal. DTO only (id, status, timestamps, node logs). `trigger_type: MANUAL`.
6. Persist `executions` (`RUNNING` → `SUCCESS` / `FAILED`) and one `execution_node_logs` row per visited node (`node_id` = instance id, `node_key` = `data.key`). Stop on first node failure.
7. HTTP: 404 missing version; 403 caller cannot run that workflow; 400 empty `edges` or broken chain.
